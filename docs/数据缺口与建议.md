> 基于 51 个 MCP 工具 × 多个真实产品的实测（2026-7-8）。
> 巡检知识库共 31 个异常点位，本文档说明每个点位的数据依赖是否满足。

## 一、数据满足度总览

| 满足度 | 点位数 | 说明 |
|---|---|---|
| ✅ 完全满足 | 14 | 数据齐全，可直接判定 |
| ⚠️ 部分满足 | 9 | 主数据有，缺基线/历史/子维度，需加工或降级 |
| ❌ 完全缺失 | 8 | 数据源不存在或无权限，当前判不了 |

## 三、⚠️ 部分满足（有主数据，缺一块，需应对）

| 异常点位 | 有什么 | 缺什么 | 现在怎么搞 |
|---|---|---|---|
| **自然流量异常** | ad_optimization 有自然/广告订单占比 | 每日自然占比序列 | **单日窗口循环 ad_optimization 补每日** → 入库 daily 表 |
| **卡位异常** | direct_competitors 竞品清单 | 本产品在竞品集的排名基线 | 数据链弱，**暂降级为 LLM 观察项**，不做确定性判定 |
| **评分异常（基准B）** | 当前星级 | 目标评分 TARGET_STAR_RATE（az_extend 有但常为 None） | 目标评分为空时**只跑基准A**，跳过基准B |
| **滞销异常** | 可售库存 | 超龄库龄/超龄仓租 | **无超龄字段，暂挂起**，等 ERP 补超龄库存接口 |
| **放量未执行** | 销量/ACOS/库存都有 | 需组合5条件+自然占比趋势 | 数据够，**待 rule_engine 实现组合判定** |
| **近期集中差评** | 评论内容文本 | 14天新增评论的时间戳 | **交 LLM node_review 读评论文本**归类，量化阈值降级 |
| **类目异常** | 当前类目路径 | ERP 类目基准做比对 | **需接 ERP 类目基准**，暂用 LLM 判断明显错配 |
| **属性信息异常** | 属性字段 | ERP 属性基准 | 同上 |
| **广告花费不足方向** | 每日花费 | — | 数据够，rule_engine 补下降方向判定 |

## 四、❌ 完全缺失（数据源不存在，当前判不了）

| 异常点位 | 缺的数据 | 影响 | 建议 |
|---|---|---|---|
| **链接不可售/下架/被抑制** | 后台链接状态、报价、抑制标记 | 🔴 S0 大类瘫痪 | **命门1**：推动接 `get_link_status` 接口或给 az_extend 加状态字段 |
| **Buy Box 丢失** | BuyBox 状态/价格/配送 | 🔴 S0 判不了 | 同命门1 |
| **主图/图片/标题/五点/A+ 变更** | 内容变更记录 + ERP 基准 | 内容完整性大类判不了 | **命门2**：推动接 `get_changed_records` + ERP 内容基准 |
| **变体掉线/父子体被拆** | 父子体挂接实时状态 | 变体级 S0 判不了 | parent_listing_detail 只有静态结构，需实时挂接状态 |
| **合规异常** | 平台合规提示/认证状态 | 合规 S0 判不了 | 接平台合规提示字段 |
| **子体库存快照** | listing_inventory 全空 | 分色库存判不了 | 工具返回空，需排查数据源 |
| **促销异常** | 前台促销展示 + 活动审核状态 | 促销判不了 | 接活动配置+前台促销接口 |
| **滞销超龄维度** | 超龄库存量/超龄仓租/FBA库龄 | 滞销判不了 | 接 FBA 库龄接口 |

## 五、命门优先级（决定能覆盖多少比例）

1. **命门1 · 链接状态/BuyBox**（最高优先）
   - 影响：整个「链接状态异常」大类（4 个 S0 点位）
   - `az_extend_detail` 已能调通（120 字段），说明加字段/加权限有通道 → **建议在 az_extend 里补 listing_status / buybox_status 字段**，是最省事的路径

2. **命门2 · 内容变更记录**
   - 影响：「内容完整性异常」大类（5 个点位）
   - 需要变更流水 + ERP 内容基准两样

3. **子体库存快照修复**
   - `listing_inventory` 工具全空，可能是数据管道断了 → 排查即可，不是没通道

---

## 六、当前可交付的判定能力

**不接任何命门，用已同步的本地库数据，14 个点位可判定**（覆盖交易表现、库存可售、库存积压、售后评分退款、转化率、目标偏离等核心场景），已足够支撑「LLM 读精确数据判定」跑起来。命门接通后再逐步补链接状态/内容完整性大类。
