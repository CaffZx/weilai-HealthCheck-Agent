# 本地中控联调运行手册

## 1. 安全边界

本地联调继续使用 `INTERNAL_ONLY` 主配置，不启动 Scheduler、Patrol Worker、Delivery Worker
或 Feedback。复盘 MCP 只能监听 `127.0.0.1`、`localhost` 或 `::1`，不能直接监听公网网卡。
数据库仅使用 MySQL，禁止创建或读取 SQLite。

所有凭据只通过当前终端环境变量注入，不写入仓库、命令脚本或日志。建议在专用终端中用
静默输入组装 `PATROL_DATABASE_URL`，终端结束后凭据随进程环境销毁。

## 2. 环境变量

本地复盘合同和协议冒烟需要：

```text
PATROL_DATABASE_URL
AZLISTING_GATEWAY
MCP_API_KEY
REVIEW_MCP_ENABLED=true
REVIEW_MCP_HOST=127.0.0.1
REVIEW_MCP_PORT=8791
```

开发测试库 JDBC 使用 `useSSL=false`，对应 SQLAlchemy/PyMySQL URL 必须带
`?charset=utf8mb4&ssl_disabled=true`；生产环境如启用 TLS，应改为正式 CA 与证书校验配置。

巡检向中控提交结果时另需：

```text
CONTROL_CENTER_MCP_URL=http://{中控测试地址}:8756/mcp
CONTROL_CENTER_MCP_TOKEN
```

## 3. 预检与启动

```bash
python -m scripts.local_integration preflight
python -m scripts.local_integration serve-review
```

另一个终端执行协议冒烟：

```bash
python -m scripts.local_integration smoke-review
python -m scripts.local_integration smoke-azlisting
```

预检必须确认数据库 revision 为 `0005_patrol_review`。协议冒烟只执行 `initialize` 和
`tools/list`，不执行真实复盘或事实查询，也不写数据库。AZListing 冒烟只输出发现的工具
数量，不输出工具参数、令牌或响应数据。

## 4. 联调顺序

1. 本地 MySQL revision 与健康预检；
2. 本地复盘 MCP 的 `initialize`、`tools/list`；
3. 使用 Fake MCP 和脱敏复盘请求验证中控调用合同；
4. 选择测试库已有基线快照，执行真实只读 AZListing 复盘；
5. 配置中控测试地址，提交 `submit_patrol_batch` v2.0 脱敏样例；
6. 需要中控主动访问本机时，再建立带 Bearer 鉴权的安全隧道，不直接暴露 8791。

v2.0 脱敏样例包含至少一条 `proposal.anomalies`，每条 `proposal.details` 都使用
`anomalyUid` 引用同一建议中的异常。首次建议主单和明细默认发送 `PENDING_APPROVAL`；
中控应逐经营单元返回 `SUCCESS`、`PARTIAL_SUCCESS` 或 `FAILED`，不得只返回整批 HTTP 状态。

## 5. 完整本地闭环

经营模式 Agent 或中控测试环境不可用时，可分别启动只读经营模式 Mock 和中控 Mock：

```bash
python -m scripts.mock_operating_mode_mcp
python -m scripts.mock_control_center_mcp
python -m scripts.local_integration serve-review
python -m scripts.run_full_local_e2e
```

`run_full_local_e2e` 固定使用测试经营单元 `1562/B0EXAMPLE0/FS04026-zhu`，从环境变量
读取测试 MySQL 与 AZListing 凭证。它执行 `MANUAL` 巡检、真实事实采集和 MySQL 快照，查询
只读经营模式 Mock，组装明确标记的模拟中控建议，经 MySQL Outbox 提交中控 Mock，再使用
中控回执中的 `proposalId` 调用巡检复盘 MCP 并重新采集真实事实。不得把该驱动器用于生产库。

真实与模拟边界必须保留：AZListing 事实、巡检分析、MySQL 快照和复盘事实是真实测试数据；
经营模式响应、中控、负责人、标签和专业建议是 Mock。真实负责人缺失、事实不足时不得用
模拟字段伪装成生产结论，中控载荷的 `rawAnalysis.isSimulated` 和 `simulatedFields` 必须保留。

巡检和联调载荷都使用完整自然日：巡检日不计入事实窗口，默认 30 天窗口截止到巡检日前
一天；关键词排名使用最近 14 个完整自然日。以 2026-08-05 为例，中控的事实快照窗口必须
显示 2026-07-06 00:00:00～2026-08-04 23:59:59，经营指标日期应选择 2026-08-04；
关键词排名查询参数必须为 2026-07-22～2026-08-04。
