## 4. 已完成改造

- 预演连接升级为 `immutable` + `query_only`，不会读取旁路 WAL 或创建临时写入；
- 报告输出源文件大小、事件 ID、问题点位和全部候选经营单元；
- 支持负责人审查后的显式 JSON 身份映射；
- 映射必须精确命中源库候选，非法、重复或未使用映射全部 fail-closed；
- 映射应用后仍会重新计算全部身份、问题点位和状态阻断。
