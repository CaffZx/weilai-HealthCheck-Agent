# 模块 2　异常字典（分类与问题点位）



系统能识别的全部异常清单，Agent 识别与运营理解共用，共 7 大类。本字典只做一件事——把每个异常"是什么"定义清楚：每个大类给"定义 + 边界"，每个问题点位只给定义。

范围约定：

- 数据来源、识别字段属工程实现，由独立的「识别规则配置表」维护，本字典不收录。

- 本模块中涉及的默认识别阈值为业务初始值，可在影子期 / 运营反馈后统一校准；具体字段与阈值配置由「识别规则配置表」维护。

- 标注 [补充] 的点位为在权威定义基础上补充的常见场景，供运营删减确认；其余点位以业务方定义为准。

异常大类总览：本模块共定义 7 个异常大类，分布如下。其中交易表现类、售后异常类为"表现型异常"（需经模块 6.0 原因查证），其余为"现象即原因型"（直接处理）。

| 序号 | 异常大类 | 关注什么 | 类型 |

| --- | --- | --- | --- |

| 1 | 链接状态异常 | 链接能否正常展示/购买/销售、成交主导权 | 现象即原因型 |

| 2 | 内容完整性异常 | 页面内容是否完整、能否承接流量转化 | 现象即原因型 |

| 3 | 价格与促销异常 | 价格促销是否正常承接成交 | 现象即原因型 |

| 4 | 库存与可售异常 | 库存能否支撑继续销售 | 现象即原因型 |

| 5 | 交易表现异常 | 转化/销量/广告等结果指标 | 表现型（需查证） |

| 6 | 合规与属性异常 | 是否存在平台规则风险 | 现象即原因型 |

| 7 | 售后异常 | 差评/评分/退款等售后信号是否影响买家信任与经营 | 表现型（需查证） |



## 2.0 异常作用层级（决定基础分取列）

每个异常按作用层级分两类，决定模块 4.1 基础分取哪一列：

- 变体级异常（命中具体子体，按命中变体的主要色/次要色/长尾色取列）：库存不可售、FBA 可售库存为 0、库存不足、变体掉线、父子体关系异常、变体价差异常、主图异常、图片异常、Buy Box 丢失，以及合规与属性各项中明确命中具体子体的异常。

- 链接级异常（整条链接的事，不分变体，取链接级异常基础分列）：以上之外的全部点位（Listing 不在售/链接不可售、标题异常、五点异常、A+ 异常、促销异常、链接转化率异常下降、销量异常、ACOS 异常、广告花费异常、售后异常各项）。

合规与属性异常的兜底规则：默认按实际命中对象判定；若仅命中某个具体子体/变体字段，按变体级处理；若影响父体整体可售、整条链接展示、平台审核、商品合规状态或账号风险，则按链接级处理。

父子体关系异常的取列规则：它可能波及一个或多个子体（父体整个被拆则波及全部子体）。取列时，按受影响子体中最重要的那个变体色取——主要色被波及则按主要色列，仅长尾色被波及则按长尾色列。与"父卡严重度取最高"逻辑一致，从严处理。

关于 ACOS / 广告花费 / 销量（父体级数据）：这三个指标取的是整个父体（所有变体的汇总集合）的数据——看的是整条链接的广告花费、ACOS、单量，不是某一个变体的。它们天然没有"哪个变体"的概念，因此归入链接级、不分变体重要性，基础分取二维表的链接级异常基础分列。

通用规则（兜底）：异常若被识别为发生在某个具体子体上，按该子体的变体重要性取列；发生在父体/Listing 整体的，按链接级异常基础分列取。上述清单为常见默认归类，实际命中对象与默认不一致时以通用规则为准。

异常类型（决定是否需要原因查证）：异常按是否需要原因查证分两类——表现型异常 = 模块 2.5 交易表现类 + 模块 2.7 售后异常类的全部点位（统计数字/比率/文字反馈，现象不等于原因，背后有多个可能原因，需经原因查证（模块 6.0）过滤出真实原因后再处理）；现象即原因型异常 = 以上之外的全部点位（现象本身即明确原因，或由平台直接给出，无需查证，直接按处理建议处理）。本规则按大类绑定：2.5、2.7 新增的点位自动归为表现型。

## 2.0.1 表现型异常巡检跳过规则

部分非表现型异常一旦命中，说明该链接（或该子体）已丧失正常展示或成交能力，此时表现型异常（销量、ACOS、广告花费、转化率、自然流量、卡位、售后等）的数据已失真甚至归零，继续巡检与查因无意义。命中下表标注“跳过”的点位时，本轮巡检跳过对该链接（或该子体，视命中层级而定）表现型异常的独立判定与查因；命中“不跳过”的点位时，表现型异常巡检正常进行，可正常触发模块 3.3 共因上调规则。判断标准：该异常发生时链接是否仍能正常展示、被浏览、被下单——不能则跳过，仍能则不跳过（与严重度高低无关）。

| 大类 | 异常点位 | 严重度 | 是否跳过表现型巡检 / 依据 |

| --- | --- | --- | --- |

| 2.1 链接状态 | Listing 不在售 | S0 | 跳过 — 链接彻底无法展示/购买 |

| 2.1 链接状态 | 链接不可售 | S0 | 跳过 — 无法正常购买 |

| 2.1 链接状态 | Buy Box 丢失 | S0 | 跳过 — 直接影响成交 |

| 2.1 链接状态 | 父子体关系异常 · 父体被拆 | S0 | 跳过 — 父体展示/购买入口整体消失 |

| 2.1 链接状态 | 变体掉线 | S0 | 不跳过 — 通常只影响部分子体，链接整体仍可展示购买 |

| 2.1 链接状态 | 父子体关系异常 · 部分子体掉出 | S0 | 不跳过 — 其余子体仍正常在售 |

| 2.2 内容完整性 | 主图异常 | S0 | 跳过 — 主图缺失或错图，缺图时搜索中不可见/不可识别 |

| 2.2 内容完整性 | 图片异常 | S1 | 不跳过 — 同上 |

| 2.2 内容完整性 | 标题异常 | S0 | 不跳过 — 仍可购买，只影响匹配/点击 |

| 2.2 内容完整性 | 五点异常 | S1 | 不跳过 — 不影响展示购买能力 |

| 2.2 内容完整性 | A+ 异常 | S2 | 不跳过 — 不影响展示购买能力 |

| 2.3 价格与促销 | 变体价差异常 | S1 | 不跳过 — 不影响展示购买能力 |

| 2.3 价格与促销 | 促销异常 | S1 | 不跳过 — 不影响展示购买能力 |

| 2.4 库存与可售 | 库存不可售 | S0 | 跳过 — 已丧失成交能力 |

| 2.4 库存与可售 | FBA 可售库存为 0 | S0 | 跳过 — 已丧失成交能力 |

| 2.4 库存与可售 | 库存不足 | S0 | 不跳过 — 尚可成交，仅有断货风险 |

| 2.4 库存与可售 | 库存积压 | 见 3.13 | 不跳过 — 不影响成交能力 |

| 2.4 库存与可售 | 滞销异常 | 见 3.14 | 不跳过 — 不影响成交能力 |

| 2.6 合规与属性 | 类目异常 | S1 | 不跳过 — 仅影响识别/曝光，未实际受限 |

| 2.6 合规与属性 | 属性信息异常 | S1 | 不跳过 — 同上 |

| 2.6 合规与属性 | 合规异常 | S0 | 跳过 — 已命中平台合规限制 |

| 2.5 交易表现 / 2.7 售后 | 该两大类全部点位 | — | 不适用 — 本身即“表现型异常”，是被判断的对象，不参与本规则 |



每轮巡检独立判断：命中跳过清单的非表现型异常，在该异常存续期间（未被运营标记解决 / 未自动恢复关闭），每轮巡检持续跳过对应表现型异常的独立判定与查因；该异常解除后，自下一轮巡检起恢复正常判断，包括是否触发新的非表现型异常、以及是否需要再次命中跳过清单。是否跳过为每轮巡检独立判定的动态结果，非一次触发后静态锁定。

跳过时的任务卡填写：命中跳过清单时，任务卡“判断依据 / 数据”栏只填该非表现型异常自身实际检测到的事实，不得填写“经营指标同步下滑”等未经检测的推测或具体经营数值（详见模块 7.0）。

## 2.1 链接状态异常

定义：产品链接在前台展示、购买路径、在售状态、父子体结构或平台状态上出现异常，导致链接无法正常展示、无法正常下单，或存在影响正常销售的状态风险，或链接的成交主导权（Buy Box）异常。

边界：判断链接本身是否还能正常展示、正常购买、正常销售。

| 问题点位 | 定义 |

| --- | --- |

| Listing 不在售 | 链接前台无法作为正常在售商品展示，或后台状态不再属于正常可售范围。例如前台变狗、页面失效等。 |

| 链接不可售 | 链接无法正常购买，或后台从可售变成不可售、下架、被抑制等。边界：因后台状态本身非可售导致的归此点位；因库存维度导致的"有库存但不可售"归 2.4 库存不可售。 |

| 变体掉线 | 原本挂在父体下的子体脱离父体，导致买家无法在变体中选择。 |

| 父子体关系异常 | 父体被拆，或部分子体掉出，父体和子体关系异常，影响变体展示或销售。 |

| Buy Box 丢失 | 商品未获得 Buy Box（链接仍在售，但未拿到黄金购物车，直接影响成交）。 |



## 2.2 内容完整性异常

定义：产品链接页面中的核心内容出现缺失、错误、展示异常或审核异常，导致买家无法完整理解产品信息，进而影响点击、转化或页面承接能力。

边界：判断页面内容是否完整，是否具备承接流量和转化的基础。

| 问题点位 | 定义 |

| --- | --- |

| 主图异常 | 主图缺失,错图、不符合平台规则被禁止显示、展示异常或影响点击。 |

| 图片异常 | 副图数量＜3 张，副图未通过审核或展示异常。 |

| 标题异常 | 标题缺失、信息错误或不符合规则。 |

| 五点异常 | 五点缺失、表达异常或信息不完整。 |

| A+ 异常 | A+ 缺失、未展示或审核异常。 |



## 2.3 价格与促销异常

定义：产品当前售价、Coupon、促销活动、折扣展示或活动价格出现异常，导致链接转化下降、利润异常、Buy Box 风险增加，或销售节奏受到影响。

边界：判断价格和促销是否正常承接流量，是否影响成交效率。

| 问题点位 | 定义 |

| --- | --- |

| 变体价差异常 | 同一父 ASIN 下，流量入口颜色的不同尺码之间，或其他颜色相对主流量入口颜色之间的前台到手价差距明显偏离正常价格带，可能影响买家选择、链接动销、广告承接或主推变体转化。默认识别阈值：流量入口颜色下，不同尺码到手价相对差距 ≥40% 且绝对差距 ≥$5；或其他颜色相对主流量入口颜色到手价相对差距 ≥70% 且绝对差距 ≥$8。若价差由活动价、Coupon、清货策略、少库存控速等运营动作导致，则标记为“需运营复核”，不直接按高严重度处理。 |

| 促销异常 | ERP 系统活动配置存在但前台未展示对应促销信息；促销活动（秒杀、LD、Z 划算、Coupon 等）未生效、折扣错误，或前台展示与 ERP 配置的活动类型不一致。 |



## 2.4 库存与可售异常

定义：产品库存状态、FBA 可售库存、库存承接能力或前台可购买状态出现异常，导致链接无法正常成交，或存在短期断货、推广无法承接的风险。

边界：判断库存是否能支撑链接继续正常销售。

| 问题点位 | 定义 |

| --- | --- |

| 库存不可售 | ERP / 后台显示存在库存，但该库存状态无法用于前台销售。 |

| FBA 可售库存为 0 | FBA 当前可售库存为 0，已无法承接后续销售，属于实际断货。 |

| 库存不足 | FBA 当前可售库存大于 0，但低于未来 14 天预计消耗（过去 7 天日均销量 ×14），存在短期断货风险。 |

| 库存积压 | 可售库存相对近期消化能力和未来目标消化能力明显偏高，存在库存占压、滞销或长期仓储费风险。具体按“可售天数 + 未来目标累计”双指标交叉判定，分级见模块 3.13。 |

| 滞销异常 | 已产生超龄仓租，且超龄库存短期无法消化、费用损失达到规模的库存异常。该点位只看超龄库存是否卖得掉，与库存积压看整体可售库存不同；准入与分级见模块 3.14。子 ASIN 查、父 ASIN 汇总。 |



## 2.5 交易表现异常

定义：链接在销量、订单、曝光、点击、转化率、广告成交、自然订单占比、卡位等经营指标上出现异常波动，说明链接当前流量获取能力、成交能力或流量承接能力出现问题。

边界：判断链接是否还能正常获得流量并完成成交。本类异常均为表现型异常，现象不等于原因；触发后需进入模块 6.0 进行原因查证，确认真实原因后再输出处理建议。

| 问题点位 | 定义 |

| --- | --- |

| 链接转化率异常下降 | 链接转化率（整条链接，链接级）较历史水平或类目平均水平明显下降，说明链接成交承接能力变弱。按周维度判定，分级见模块 3.10。 |

| 销量异常 | 当前销量较过去 7 天日均连续 ≥3 天大幅偏离。下降方向作为销量异常，关注销量下滑、断货、掉权或转化问题；上升方向作为“销量增长提示”，用于提示链接出现增长信号。若同时满足“放量未执行”条件，则不单独输出销量增长提示，转入“放量未执行”。分级见模块 3.6。 |

| ACOS 异常 | 实际 ACOS 连续 ≥3 天明显高于该产品过去 7 天平均 ACOS，说明广告投入产出效率变差。分级见模块 3.6。 |

| 广告花费异常 | 实际广告花费连续 ≥3 天明显偏离过去 7 天平均花费，包括花费超出和花费不足两个方向。分级见模块 3.6。 |

| 目标偏离 | 实际单量连续低于运营在 ERP 设定的日均目标单量或月目标节奏，说明当前销售结果未达到运营目标。分级见模块 3.7。 |

| 自然流量异常 | 自然订单占比连续低于近 7 天平均水平，说明链接自然流量贡献走弱。按三窗口判定，分级见模块 3.8。 |

| 卡位异常 | 本产品在直接竞品集合中的排位下滑，说明竞争入口位置变弱，可能进一步影响自然流量和销量。分级见模块 3.9。 |

| 放量未执行 | 产品已满足放量条件，但广告投入未跟上，属于“该做没做型”机会损失异常。判定见模块 3.12。 |



## 2.6 合规与属性异常

定义：产品链接因类目、属性、平台规则、合规字段、认证要求、敏感表达或页面字段问题，存在被限制、被抑制、审核失败、下架或影响系统识别的风险。

边界：判断链接是否存在平台规则风险，是否会影响链接安全和系统识别。若问题表现为页面内容缺失、错图、标题 / 五点 / A+ 信息不完整，归 2.2 内容完整性异常；若问题由平台规则、敏感表达、合规要求、类目 / 属性识别错误导致，归本类。

| 问题点位 | 定义 |

| --- | --- |

| 类目异常 | 商品类目被错误修改，或类目与产品实际不匹配，影响平台识别、曝光或合规判断。 |

| 属性信息异常 | 颜色、尺码、材质、适用场景等属性缺失、错误或与产品实际不一致，影响系统识别、筛选曝光或买家理解。 |

| 合规异常 | 商品已经命中平台合规要求、认证要求、禁售 / 限售规则，或后台已有明确合规提示，需要修复后才能降低限制风险。 |



## 2.7 售后异常

定义：产品近期在差评、评分、退款等售后维度出现异常变化，可能影响买家信任、链接转化与长期经营。售后异常为表现型异常——现象（差评数 / 评分 / 退款率）不等于原因，需由 Agent 读取评论内容、退款理由等文字，归类出真实原因（尺码 / 质量 / 物流 / 页面描述等）。

边界：判断差评、评分、退款等售后信号是否已经影响或即将影响买家信任、链接转化与长期经营。售后异常只判断售后表现是否异常，具体原因需进入模块 6.0 读取评论内容或退款理由后确认。

| 问题点位 | 定义 |

| --- | --- |

| 近期集中差评 | 14 天内新增多个低星评价，或多条低星 / 负面评论集中反馈同一类问题；当新增负面反馈数量 > 现有评分数的 20% 时，触发近期集中差评。 |
