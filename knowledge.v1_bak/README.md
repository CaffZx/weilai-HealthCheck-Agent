# 知识库

链接预警 Agent 知识库，8 个模块，从 docx 抽取转换为 md。改动直接编辑对应 md，接口触发热加载即可，不需要重启服务。

| 文件 | 内容 |
|---|---|
| [00_总则.md](00_总则.md) | 术语对齐（S / T / P 三层） |
| [01_产品标签与判定基线.md](01_产品标签与判定基线.md) | 抓取输入清单 + 系数映射 |
| [02_异常字典.md](02_异常字典.md) | 分类与问题点位 |
| [03_异常严重度判定规则.md](03_异常严重度判定规则.md) | S0/S1/S2 判定 + 各专项 |
| [04_优先级计算参数.md](04_优先级计算参数.md) | 执行分数公式 + 阈值 |
| [05_升降级与解除规则.md](05_升降级与解除规则.md) | 事件级流转 |
| [06_异常处理建议库.md](06_异常处理建议库.md) | 6.0 / 6.2 / 6.3 三级建议 |
| [07_运营输出规范.md](07_运营输出规范.md) | 任务卡字段与排列 |

## 关键约定

- **S = 异常严重度**（S0/S1/S2）— 判定输入
- **T = 产品定位**（T0/T1/T2/T3）— 权重
- **P = 执行优先级**（P0/P1/P2）— 最终输出
