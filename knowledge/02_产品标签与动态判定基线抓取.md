# 业务巡检Agent知识库 - 切片 02：产品标签与动态判定基线抓取

本切片定义 Agent 需要从 ERP、打标系统或系统计算结果中抓取哪些标签与动态基线。输入是产品定位、阶段、淡旺季、广告目的、关键词类型、变体重要性和近 7 天广告基线，输出是模块 4 打分系数以及模块 3/6 广告类判定和查因口径。

## 模块 1　产品标签与判定基线抓取

本模块不负责给产品打标签，也不负责计算经营指标——产品定位、阶段、淡旺季、广告目的、关键词类型、变体重要性等标签的赋值由上游 ERP/打标系统完成；近 7 天平均 ACOS、近 7 天平均花费等动态经营数据由系统计算或从 ERP 抓取。本系统只做三件事：抓取这些输入，定义标签如何映射成执行分数的系数，以及定义动态判定基线如何影响异常判定口径。因此本模块只保留”输入项 → 系数/影响”的对照，不复述上游的判定阈值或准入条件。

### 1.0 需抓取的输入清单

| 输入项 | 取值类型 | 来源 | 在本系统中的用途 |
| --- | --- | --- | --- |
| A. 标签类输入 |  |  |  |
| 产品定位 | 单选 T0–T3 | ERP 抓取 | 定位系数（打分主权重） |
| 产品阶段 | 单选 | ERP 抓取 | 阶段系数 + 调节异常判定口径 |
| 淡旺季 | 单选 | ERP 抓取 | 淡旺季系数 |
| 广告目的 | 单选 / 多选 | ERP 抓取 | 调节广告类异常判定口径 |
| 关键词类型 | 单选 / 多选 | ERP 抓取 | 调节广告类异常诊断口径 |
| 变体重要性 | 单选（子体级） | ERP 抓取 | 变体级异常的基础分取列（模块 4.1）：主要色 / 次要色 / 长尾色。库存类异常同样按变体重要性取列，见模块 2.0 |
| B. 动态判定基线数据 |  |  |  |
| 近 7 天平均 ACOS | 动态经营数据 / 判定基线 | 系统计算或 ERP 抓取 | ACOS 异常判定基线（模块 3.6） |
| 近 7 天平均花费 | 动态经营数据 / 判定基线 | 系统计算或 ERP 抓取 | 广告花费异常判定基线（模块 3.6） |

### 1.1 产品定位 → 定位系数

| 定位 | 名称 | 代码枚举（ERP 值） | 定位系数 |
| --- | --- | --- | --- |
| T0 | 战略级产品 | P0_PRODUCT | 1.5 |
| T1 | 重点产品 | P1_PRODUCT | 1.2 |
| T2 | 常规产品 | P2_PRODUCT | 1.0 |
| T3 | 长尾产品 | P3_PRODUCT | 0.6 |

抓取到 ERP 枚举值后按上表映射为本库 T0–T3 与定位系数。代码枚举里的 P 是 ERP 既有值，与异常严重度 S、执行优先级 P 无关。定位系数详见模块 4.2。

### 1.2 产品阶段 → 阶段系数

| 阶段（ERP 值） | 中文 | 阶段系数 | 对异常的影响 |
| --- | --- | --- | --- |
| harvesting | 收割利润 | 1.3 | 利润直接到手、体量最大，异常代价最高 |
| pushing | 推进 | 1.2 | 投入重、不可逆，异常易丢排名势能 |
| maintaining | 维持 | 1.0 | 基准，风险敞口低 |
| testing | 测试 | 0.8 | 花费少未验证；但污染测试读数的异常（承接、词路）严重度应单独拔高 |
| liquidating | 清货 | 0.4 | 准备退出，紧急度最低 |

阶段系数详见模块 4.3（已确认”收割第一”）。产品阶段同时影响部分异常判定口径，例如广告类异常、库存类异常、清货类动作建议等。

### 1.3 淡旺季 → 淡旺季系数

| 淡旺季阶段 | 淡旺季系数 |
| --- | --- |
| 旺季 | 1.3 |
| 旺季前期 | 1.2 |
| 旺季末期 | 1.0 |
| 淡季 | 0.7 |

淡旺季系数详见模块 4.4。

### 1.4 广告目的 → 异常判定口径

不进打分权重，只调节广告类异常的判定敏感度。

| 广告目的（ERP 值） | 对异常判定的影响 |
| --- | --- |
| traffic（引流） | ACOS 偏高属正常，ACOS 类容忍度高；流量骤降更敏感 |
| conversion（转化） | 转化率、ACOS、订单量异常更敏感 |
| ranking（冲排名） | 关键词排名、自然位掉落更敏感 |
| profit（利润） | ACOS 超标、花费超出类最敏感，应上调严重度 |

### 1.5 关键词类型 → 异常诊断口径

不进打分权重，只调节广告类异常诊断敏感度。

| 关键词类型（ERP 值） | 对异常判定的影响 |
| --- | --- |
| generic（大词/泛词） | 高竞争掉位属常态，敏感度低 |
| long_tail（长尾词） | 转化、ACOS 异常更敏感（整体 ACOS 锚定点） |
| competitor（竞品词） | 被竞品反打、掉位较敏感 |
| brand（品牌词） | 品牌词被截流对品牌防御型产品高优先级 |
| custom（自定义词） | 按词表单独配置 |

历史值 broad 读取时映射为 generic。

### 1.6 动态判定基线：近 7 天平均 ACOS / 近 7 天平均花费

近 7 天平均 ACOS 与近 7 天平均花费不属于产品标签，而是系统按该产品过去 7 天广告表现计算出的动态判定基线。它们本身不是异常，也不进打分权重，仅作为广告类异常的判定基线：当前 ACOS / 花费相对近 7 天平均值偏离到一定程度才算异常并判定严重度，判定细则见模块 3.6。近 7 天平均 ACOS 用于 ACOS 异常判定；近 7 天平均花费用于广告花费异常判定。注意：近 7 天平均花费不是”预算设置值”。广告花费异常判断的是实际花费相对过去 7 天平均花费的偏离，不是预算额度本身的变化。

### 1.7 变体重要性（子体级标签）

由 ERP 对父 ASIN 下每个子体（颜色）打好的分类，本系统直接抓取，用于变体级异常的基础分取列（模块 4.1）。仅对变体级异常生效，链接级异常不适用；库存类异常（库存不可售、FBA 可售库存为 0、库存不足）在子体层识别，同样按命中子体的变体重要性取列，见模块 2.0（其巡检频次由巡检频次规则文件统一维护）。

| 变体重要性（ERP 值） | 说明 |
| --- | --- |
| 主要色 | 流量入口颜色，承担主要流量与销量 |
| 次要色 | 销售占比稍高的颜色 |
| 长尾色 | 重要度很低的颜色 |

同一变体级异常（如主图异常、库存不可售）命中不同重要性的变体，严重度相同但基础分不同：主要色 > 次要色 > 长尾色（见模块 4.1）。库存类异常同样适用本差异。
