# 业务巡检Agent知识库 - 切片 12：运营输出规范与父 ASIN 任务卡示例

本切片定义最终任务卡向运营展示的字段结构、排列归集规则、字段来源和示例输出。输入是模块 0–6 形成的标签、异常、严重度、执行分数、状态和处理建议，输出是一张以父 ASIN 为单位、包含异常明细和复查动作的运营任务卡。

## 模块 7　运营输出规范（任务卡）

前置模块 0–6 完成标签抓取、异常判定、严重度判定、优先级打分、状态流转与输出路径判断；模块 7 定义最终任务卡如何展示给运营。本模块只定义输出内容，不限定输出形态（ERP 列表页、推送通知等由实现侧决定）。

### 7.0 总则

- 以父 ASIN 任务卡为单位呈现：一个父 ASIN 一张卡，卡内列出该 ASIN 下全部未关闭异常明细。

- 三档执行优先级（P0/P1/P2）展示方式统一，不因优先级不同而改变字段结构；优先级只体现在排序与时限标识上。

- 卡内多条异常按该条异常的执行分数从高到低排列（贴近处理紧迫度），不按变体重要性或严重度单独排。

- 判断依据、处理建议每条异常各自携带（不同异常依据与建议不同）；初步原因 / 原因说明仅表现型异常输出，非表现型具体异常不输出原因字段。

销量增长提示与放量未执行共现去重：若”销量增长提示”与”放量未执行”同时命中，任务卡只输出”放量未执行”；销量增长数据作为该任务卡的判断依据展示，不再单独占用一条异常明细。

任务卡字段标准化原则：父卡级字段与异常明细基础字段固定输出，不因 P0/P1/P2 或异常类型不同而减少字段；初步原因 / 原因说明仅表现型异常输出，非表现型具体异常不设置该字段；字段暂无数据时填”无 / 待补充 / 不适用”，不得省略字段。表格中的”验证方式 / 查证动作”属于 Agent 内部逻辑，最终任务卡只输出已验证成立的原因、对应异常点位、判断依据和处理建议。

跳过巡检时不编造表现型数据：若本轮巡检命中了触发”跳过表现型异常巡检”的非表现型异常（详见模块 2.0.1 跳过清单），则该链接的表现型异常未经检测，任务卡”判断依据 / 数据”栏只填该非表现型异常自身实际检测到的事实，不得填写”经营指标同步下滑”“销量 / 花费下降”等未经检测的推测性描述或具体数值；此类未检测的经营数据不得出现在任务卡任何字段中。

### 7.1 任务卡字段结构

A. 定位信息（父卡级，显示一次）

| 字段 | 说明 |
| --- | --- |
| 店铺 / 站点 | 经营主体与站点 |
| 父 ASIN / 产品名 | 任务归属与展示主体 |
| 负责人 | 该链接的运营负责人 |
| 产品定位（T） | T0 / T1 / T2 / T3 及中文定位，用于解释该任务为什么优先级较高或较低 |
| 产品阶段 | 测试 / 推进 / 收割 / 维持 / 清货，用于解释阶段系数与处理策略 |
| 淡旺季 | 旺季 / 旺季前期 / 旺季末期 / 淡季，用于解释淡旺季系数与库存、推广判断 |

B. 优先级信息（父卡级，显示一次）

| 字段 | 说明 |
| --- | --- |
| 执行优先级 | P0 / P1 / P2 |
| 处理时限 | 当天 / 3 天内 / 7 天内处理（与执行优先级对应，见模块 4.6） |
| 父卡严重度 | 取卡内所有子异常的最高严重度（S0/S1/S2） |
| 产品执行分数 | 模块 4 计算出的产品执行分数，用于排序与 P0/P1/P2 映射；可按系统展示精度显示 |
| 下一次复查时间 | 根据处理时限、人工备注或固定复查规则生成；运营设置了复查时间的以运营设置时间为准（见模块 0.1）；用于跟进异常是否恢复 |
| 当前状态 | 未处理 / 处理中 / 已处理 / 误报 / 不需处理 / 自动恢复关闭等状态 |

C. 异常明细（每条异常一行，按该条执行分数从高到低排列）

明细的”原因 / 处理建议”栏按异常类型展开：非表现型具体异常直接取模块 6.2 的”异常点位命中后输出”；表现型异常按模块 6.0 查因、路由和输出。若表现型异常经 6.0 查因后，真实原因指向非表现型具体异常点位，则保留原表现型异常明细，同时将该具体异常点位作为原因说明 / 处理指向，并调用模块 6.2 对应输出。若该具体点位未命中 6.2 建议表，则调用 6.3 大类兜底输出，并标记”大类兜底 / 建议表待补充”。

| 字段 | 说明 |
| --- | --- |
| 异常类型 + 问题点位 | 大类（如库存与可售）+ 具体点位（如 FBA 可售库存为 0） |
| 命中变体 + 变体重要性 | 具体子体（如黑色/M 码）+ 主要色/次要色/长尾色；链接级异常标注”链接级”（链接不可售、库存类异常均按变体级标注命中子体与变体重要性） |
| 该条严重度 | S0 / S1 / S2 |
| 作用层级 | 链接级 / 变体级 |
| 判断依据 / 数据 | 触发该异常的客观数据（如”实际 ACOS 48% vs 目标 25%，连续 4 天”） |
| 初步原因 / 原因说明（仅表现型异常） | 仅表现型异常填写，由模块 6.0 查因结果生成；非表现型具体异常不输出该字段。 |
| 处理建议 | 来自模块 6 的最终输出内容：表现型异常取 6.0 输出；非表现型具体异常取 6.2”异常点位命中后输出”；6.2 无具体点位建议时取 6.3 大类兜底输出。 |
| 上次处理记录 | 历史处理动作 + 时间（复发时尤其重要） |
| 该条执行分数 | 该异常明细对应的单异常执行分数；用于解释卡内排序，不等同于产品执行分数 |
| 复查要求 / 下一步动作 | 本条异常需要复查的时间、条件或运营下一步动作；运营设置复查时间优先 |
| 异常状态 / 操作项 | 本条异常当前状态及可执行动作，如处理、误报、不需处理、降级、转派、标记高风险 |

### 7.2 排列与归集规则

- 父卡内多条异常：按该条异常执行分数降序排列，最紧迫的异常排最前。

- 父卡严重度与排序解耦：父卡严重度取子异常最高（展示用），卡内排序按执行分数（紧迫度用）。

- 归集不丢信息：每条子异常的变体、变体重要性、严重度、判断依据均独立保留，不因归集到父卡而合并或丢失。

输出不丢查证结果：表现型异常的任务卡明细只输出已验证成立的原因与已排除项；内部查证动作（如”查是否并发某异常”）不得原样呈现给运营。若表现型异常经 6.0 查因后，真实原因指向非表现型具体异常点位，则本条明细保留原表现型异常，同时展示该具体异常点位作为处理指向，并调用模块 6.2 的”异常点位命中后输出”；若该点位未命中 6.2 建议表，则调用 6.3 大类兜底输出。

字段缺失处理：当 ERP、事件记忆或外部数据暂缺时，字段保留但填”待补充 / 数据不足 / 不适用”，不得删除字段；若关键字段缺失影响异常正式判定，按对应模块的数据不足规则处理。

### 7.3 字段来源对照

| 字段 | 来源 |
| --- | --- |
| 店铺/站点、父 ASIN、负责人、命中变体、变体重要性 | ERP 抓取（模块 1） |
| 异常类型、问题点位、作用层级 | 模块 2 |
| 该条严重度、判断依据、父卡严重度 | 模块 3 初判 + 模块 6.0 查因二次修正（共因上调 / 回落） |
| 执行优先级、处理时限 | 模块 4（执行分数 → 阈值） |
| 初步原因 / 原因说明 | 仅表现型异常由模块 6.0 查因结果生成；非表现型具体异常不输出。 |
| 处理建议 | 模块 6 最终输出规则生成：表现型异常取 6.0，非表现型具体异常取 6.2，必要时取 6.3。 |
| 上次处理记录 | 事件记忆（历史处理状态） |
| 产品定位、产品阶段、淡旺季 | ERP 抓取（模块 1），并映射到模块 4 的系数 |
| 产品执行分数、该条执行分数 | 模块 4（单异常执行分数、产品执行分数） |
| 下一次复查时间、当前状态、异常状态 / 操作项 | 模块 5 复查/解除规则（运营设置复查时间优先，见模块 0.1）+ 事件记忆 / 处理状态流转 |

初步原因 / 原因说明与处理建议的具体话术，按模块 6 输出规则生成：表现型异常取 6.0 输出；非表现型具体异常取 6.2”异常点位命中后输出”；必要时取 6.3 大类兜底输出。

严重度变更留痕：该条严重度如触发共因上调或回落，须留存完整变更轨迹（变更时间、变更前后档位、触发 / 回落依据），例如”初判 S1 → 因 3 项共因于 X 月 X 日上调至 S0 → X 月 X 日复扫共因不足回落至 S1”，供后续复盘共因上调规则的实际效果与阈值校准。

### 7.6 共因去重 + 共因上调联动示例

本示例用于说明两条规则的联动：① 共因去重——多个表现型异常合并为关联现象展示，不重复生成主任务、不参与并发加成；② 共因上调（模块 3.3）——固定档位点位若被查因确认为 3 项及以上表现型异常的共同原因，严重度上调一档，处理建议沿用原档位。

示例产品：T2 常规产品、维持期、淡季。本轮巡检命中”类目异常”（初判 S1，属不跳过清单），经模块 6.0 查因确认为自然流量异常、卡位异常、销量异常 3 项表现型异常的共同原因，触发共因上调，S1 升至 S0。

输出说明：运营最终看到的是”类目异常”这一条主任务（严重度已因波及 3 项表现型异常由 S1 上调至 S0），以及自然流量异常、卡位异常、销量下降三条关联现象。本例同时演示：① 共因去重——3 个表现型异常合并展示为关联现象，不重复生成主任务、不参与并发加成；② 共因上调——因共因数量达到 3 个阈值，类目异常严重度由初判 S1 上调至 S0，处理建议沿用原 S1 档位内容不变。
