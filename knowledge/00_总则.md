# 模块 0　知识库总则



## 0.3 关键术语对齐（沿用方案口径，避免混淆）

| 术语 | 含义 | 取值 |

| --- | --- | --- |

| 异常严重度 | 异常本身有多严重，是执行分数的基础分 | S0 / S1 / S2 |

| 产品定位 | 产品战略价值层级，折入执行分数作定位系数 | T0 / T1 / T2 / T3 |

| 执行优先级 | 运营最终先做哪个，由执行分数按阈值映射 | P0 / P1 / P2 |



三层各用一个字母从字面区分，避免 Agent 混淆：S=异常严重度（输入/基础分，S0/S1/S2），T=产品定位（权重，T0–T3），P=执行优先级（最终输出，P0/P1/P2）。本库模块 2、3 判定产出的一律是 S；执行优先级 P 是模块 4 打分后的最终输出。
