# 业务巡检Agent知识库 - 切片 11：处理建议取用规则、非表现型建议表与大类兜底

本切片定义正式异常如何取处理建议，包括精确匹配、同点位建议补位和大类兜底。输入是已命中的非表现型具体异常点位及严重度，输出是任务卡中的处理建议；当具体建议缺失时，输出对应大类兜底并标记建议表待补充。

### 6.1 处理建议取用规则（三级兜底，保证正式异常有处理建议输出）

精确匹配：异常点位 + 严重度在下表命中 → 取该条建议。

同点位建议补位：异常点位已命中且 S 档已判定，但 6.2 缺少该点位对应 S 档的专属处理建议时，取该点位最接近的更严重档建议，并标注「参考同点位 SX 建议」；该补位仅用于处理建议取用，不改变原异常严重度、优先级和打分。

大类兜底：异常大类已识别，但具体异常点位未命中 6.2 建议表 → 保留原具体异常点位，取该大类兜底建议，并标记「大类兜底 / 建议表待补充」，定期捞出补充进表。最终输出不得只展示大类名称。

变体重要性不在本表体现：变体掉线、变体价差、库存类等已合并为单条带条件句的建议，严重度与基础分由模块 3、4.1 判定，处理建议按命中变体重要性输出对应分支。父子体关系异常按父体结构级 / 链接级处理，不参与主要色 / 次要色 / 长尾色分支。广告相关动作默认仅针对有广告投放的变体（其余颜色基本未开广告）。

### 6.2 处理建议表

6.2 用于非表现型异常及具体异常点位的输出。与 6.0 表现型异常不同，本节不再进行原因查证；只要具体异常点位已命中，即按对应行的”异常点位命中后输出”生成处理内容。表现型异常的查因、路由和输出统一按模块 6.0 执行，不在 6.2 中重复设置处理建议。交易表现异常、售后异常等已在 6.0 中设置独立查因与输出逻辑的异常，不再作为 6.2 独立小节保留（因此本节小节编号中不设 6.2.5，与异常大类序号 5 交易表现类对应留空，非内容缺失）。

共因上调点位的处理建议取用：适用模块 3.3 共因上调规则的固定档位点位（类目异常、属性信息异常、图片异常、五点异常、A+ 异常、变体价差异常、促销异常）因触发共因上调而升级时，处理建议沿用其原档位（如 S1）对应内容，不单独新增更高档位处理建议；任务卡严重度标签须注明”初判 Sx，因经模块 6.0 查因确认为 3 项及以上表现型异常共同原因，按 3.3 规则上调至 Sy”，使运营可识别该升级来源。

#### 6.2.1 链接状态异常

| 异常点位 | 严重度 | 异常点位命中后输出 |
| --- | --- | --- |
| 链接不可售 | S0 | 检查后台链接状态、前台展示、平台提示，排查库存、价格、配送、合规、类目、属性、平台限制等触发原因-配合开 case 处理；根据已识别的变体重要性，仅输出命中的分支动作：① 若为主要色不可售：优先恢复，并检查广告是否仍投向该变体，必要时暂停其广告；② 若为次要色 / 长尾色不可售：核实销售占比后恢复；若无广告投放，则无需广告暂停动作，但仍需处理链接不可售异常。输出时不得同时输出未命中的分支动作。 |
| 变体掉线 | S0 | 先恢复掉线子体挂接，并核实该变体销售占比与广告投放情况；根据已识别的变体重要性，仅输出命中的分支动作：① 若为主要色掉线：检查广告是否仍投向异常变体，必要时暂停其广告并优先恢复；② 若为次要色 / 长尾色掉线：核实销售占比后恢复挂接或调整投放；若无广告投放，则无需广告暂停动作，但仍需处理该变体掉线异常。输出时不得同时输出未命中的分支动作。 |
| 父子体关系异常 | S0 | 恢复父子体关系；排查类目、属性、变体主题、父体绑定规则和平台提示；因该异常代表父体被拆、全部子体掉出，应优先恢复父体结构。若广告仍投向原父体或异常子体，需同步检查广告承接，必要时暂停或降低相关广告；若无广告投放，则无需广告暂停动作，但仍需处理父子体关系异常。 |
| Buy Box 丢失 | S0 | 排查价格、库存、配送方式、账号绩效、竞品报价；根据已识别的变体重要性，仅输出命中的分支动作：① 若主要色 Buy Box 丢失：优先处理，并必要时暂停其高消耗广告；② 若次要色 / 长尾色 Buy Box 丢失：按成交占比评估处理；若无广告投放，则无需广告暂停动作，但仍需处理 Buy Box 丢失异常。输出时不得同时输出未命中的分支动作。 |

输出控制：涉及主要色、次要色、长尾色的处理建议时（限非库存类点位），Agent 需根据已识别的变体重要性，仅输出实际命中的分支动作，不得将主要色、次要色、长尾色的处理建议整段同时输出。若命中主要色异常，则输出主要色对应处理动作；若命中次要色 / 长尾色异常，则输出次要色 / 长尾色对应处理动作。若对应变体无广告投放，则无需广告暂停或广告调整动作，但仍需处理该链接 / 变体状态异常。

#### 6.2.2 内容完整性异常

| 异常点位 | 严重度 | 异常点位命中后输出 |
| --- | --- | --- |
| 主图异常 | S0 | 补充或替换主图，确认主图是否缺失，或因图片违规、错图、尺寸、白底、元素不合规导致-配合开 case 处理。若为”疑似错图，需人工确认”状态，先由运营确认是否错图，确认后再执行修复。 |
| 图片异常 | S1 | 核对副图数量（少于 3 张需补齐场景图、卖点图等关键图片）、图片内容、审核状态和前台展示，配合开 case 处理。 |
| 标题异常 | S0 | 核查标题是否被系统改写，修正核心关键词、规格和产品信息-配合开 case 处理。若为”疑似标题信息错误，需人工确认”状态，先由运营确认后再执行修复。 |
| 五点异常 | S1 | 根据五点实际缺失或不完整内容，补齐对应的核心卖点、材质、尺寸、场景、洗护等买家关键信息。 |
| A+ 异常 | S2 | 检查 A+ 审核、前台展示等，配合开 case 处理（子体级异常，按命中子体处理）。 |

#### 6.2.3 价格与促销异常

| 异常点位 | 严重度 | 异常点位命中后输出 |
| --- | --- | --- |
| 变体价差异常 | S1 | 检查主推变体与其他变体价差，核实各变体动销，并核实价格自动调整中设置的价格是否正确，判断是否统一价格带或调整低动销变体价格；根据已识别的变体重要性，仅输出命中的分支动作：① 若为主要色价差异常：优先处理价格差异，并同步检查广告承接；② 若为次要色 / 长尾色价差异常：按动销情况调整售价。输出时不得同时输出未命中的分支动作。若价差由活动价、Coupon、清货策略、少库存控速等运营动作导致，标记”需运营复核”，不直接按高严重度处理。 |
| 促销异常 | S1 | 检查促销/Coupon/折扣/活动价是否生效、配置与审核状态、前台展示；必要时恢复活动或调整价格承接。 |

#### 6.2.4 库存与可售异常

按业务口径，库存不可售、FBA 可售库存为 0、库存不足的处理建议不按主要色、次要色、长尾色区分；仅按”是否有广告投放”给条件句动作。

| 异常点位 | 严重度 | 异常点位命中后输出 |
| --- | --- | --- |
| 库存不可售 | S0 | 确认不可售原因（被禁止显示等），核对 ERP、后台库存、前台购买状态及配送，配合 case 处理；根据已识别的变体重要性，仅输出命中的分支动作：① 若为主要色库存不可售：优先处理并控制其广告放量；② 若为次要色 / 长尾色库存不可售：按销售占比处理；若无广告投放，则无需广告暂停或广告调整动作，但仍需处理库存不可售异常。输出时不得同时输出未命中的分支动作。 |
| FBA 可售库存为 0 | S0 | 确认补货、调拨、在途库存计划；根据已识别的变体重要性，仅输出命中的分支动作：① 若主要色 / 流量入口变体 FBA 可售库存为 0：暂停或降低其广告，避免无库存消耗流量，必要时与上级协商；② 若次要色 / 长尾色 FBA 可售库存为 0：按销售占比决定补货或进观察池。输出时不得同时输出未命中的分支动作。 |
| 库存不足 | S0 | 确认在途库存、补货计划，或者中转货物的转出；根据已识别的变体重要性，仅输出命中的分支动作：① 若为主要色库存不足：优先保障并控制其广告放量；② 若为次要色 / 长尾色库存不足：按销售占比安排补货；若无广告投放，则无需广告暂停或广告调整动作，但仍需处理库存不足异常。输出时不得同时输出未命中的分支动作。 |
| 库存积压 | S2/S1/S0 | 见 3.13，按程度给建议：S2 轻度——有轻微滞销风险，谨慎备货，评估短期目标及当前产品推广策略；S1 中度——存在明显滞销风险，放缓/暂停补货，评估通过促销、Coupon、广告加快动销，并复核目标与定价；S0 重度——滞销风险较高、可售周期远超合理水位，优先处理：评估降价清货、捆绑促销加快出清，关注长期仓储费风险，暂停补货。A、B 矛盾时附”当前卖速与目标预期不一致，请结合淡旺季复核”。 |
| 滞销异常 | S2/S1/S0 | 见 3.14（准入：有超龄+1个月清不完+单月超龄费>$20；按消化周期分级）。S2——已产生超龄仓租、短期难消化(可售{X}天)，放缓/暂停补货，评估促销、Coupon、广告加快动销，复核目标与定价；S1——滞销明显、消化周期较长，主动出清：评估降价、捆绑促销、加广告清货，暂停补货；S0——滞销严重、消化周期极长或近乎不动销，超龄仓租持续吃利润，重点处理：评估大幅降价清货、捆绑/清仓、移除或弃置部分超龄库存止损，停止补货。与库存积压同时触发时取本异常（见 3.14 共现去重）。 |

输出控制：涉及主要色、次要色、长尾色的库存处理建议时，Agent 需根据已识别的变体重要性，仅输出实际命中的分支动作，不得将主要色、次要色、长尾色的处理建议整段同时输出。若对应变体无广告投放，则无需广告暂停或广告调整动作，但仍需处理对应库存与可售异常。

#### 6.2.6 合规与属性异常

| 异常点位 | 严重度 | 异常点位命中后输出 |
| --- | --- | --- |
| 类目异常 | S1 | 检查类目路径、节点、必填属性和平台提示，必要时提交类目修正。 |
| 属性信息异常 | S1 | 核对 ERP / 后台属性、页面展示与产品实际信息，修正错误或不一致字段；如有平台必填属性未填写或填写错误，一并补齐后确认保存。 |
| 合规异常 | S0 | 根据后台合规提示定位触发原因，开 case 配合处理，并同步联系肖欢处理。（子体级异常，按命中子 ASIN 处理；若全部子体命中，按全部子体统一处理。） |

### 6.3 大类兜底建议

6.3 使用边界：6.3 仅用于非表现型异常的大类兜底。当异常大类已识别，但具体异常点位未命中 6.2 建议表时，保留原具体异常点位，并调用本节对应大类兜底输出；最终输出不得只展示大类名称。表现型异常及售后异常已在 6.0 各小节设置查因、路由和输出逻辑，不进入 6.3 大类兜底。

| 大类 | 大类兜底输出 |
| --- | --- |
| 链接状态异常 | 排查后台链接状态、前台展示、平台提示、库存、价格、配送、类目、属性、合规等环节，定位导致链接无法正常展示/购买/销售的原因，必要时配合开 case 处理。 |
| 内容完整性异常 | 核对主图、副图、标题、五点、A+ 等页面内容的展示、审核与合规状态，补齐或修正缺失/错误内容，恢复页面承接能力。 |
| 价格与促销异常 | 核查是否误调价、价格自动调整设置是否正确、Coupon / 促销 / 折扣是否生效、是否触发价格健康问题，对比历史与竞品价格，恢复合理价格与促销承接，必要时配合开 case 处理。 |
| 库存与可售异常 | 排查 FBA 可售库存、库存状态、前台可购买状态、配送与系统同步，确认补货/调拨/在途计划；若命中变体仍有广告投放且库存为 0，暂停或降低其广告避免无库存消耗流量。 |
| 合规与属性异常 | 根据平台提示排查类目、属性、必填字段、敏感表达、图片与页面字段，修正风险后提交审核，降低被限制 / 抑制 / 下架风险；若已触发后台合规限制，则开 case 配合处理，并同步联系肖欢处理。 |
