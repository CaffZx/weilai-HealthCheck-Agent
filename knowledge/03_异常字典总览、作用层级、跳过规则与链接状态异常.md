# 业务巡检Agent知识库 - 切片 03：异常字典总览、作用层级、跳过规则与链接状态异常

本切片定义异常字典的总览、异常作用层级、表现型异常是否跳过巡检的规则，以及链接状态类异常的边界。输入是异常命中对象、变体重要性和链接状态事实，输出是异常属于链接级还是变体级、是否跳过表现型巡检，以及链接不可售、变体掉线、父子体关系异常、Buy Box 丢失等点位定义。

## 模块 2　异常字典（分类与问题点位）

系统能识别的全部异常清单，Agent 识别与运营理解共用，共 7 大类。本字典只做一件事——把每个异常”是什么”定义清楚：每个大类给”定义 + 边界”，每个问题点位只给定义。

范围约定：

- 识别字段的具体工程口径由独立的「识别规则配置表」维护；各点位所需数据字段的业务级清单见模块 2.8 异常点位主索引表，来源统一写为 ERP / 平台后台 / 广告后台 / MCP 接口，不编造具体表名。

- 本模块中涉及的默认识别阈值为业务初始值，可在影子期 / 运营反馈后统一校准；具体字段与阈值配置由「识别规则配置表」维护。

异常大类总览：本模块共定义 7 个异常大类，分布如下。其中交易表现类、售后异常类为”表现型异常”（需经模块 6.0 原因查证），其余为”现象即原因型”（直接处理）。

| 序号 | 异常大类 | 关注什么 | 类型 |
| --- | --- | --- | --- |
| 1 | 链接状态异常 | 链接能否正常展示/购买/销售、成交主导权 | 现象即原因型 |
| 2 | 内容完整性异常 | 页面内容是否完整、能否承接流量转化 | 现象即原因型 |
| 3 | 价格与促销异常 | 价格促销是否正常承接成交 | 现象即原因型 |
| 4 | 库存与可售异常 | 库存能否支撑继续销售 | 现象即原因型 |
| 5 | 交易表现异常 | 转化/销量/广告等结果指标 | 表现型（需查证） |
| 6 | 合规与属性异常 | 是否存在平台规则风险 | 现象即原因型 |
| 7 | 售后异常 | 差评/评分/退款等售后信号是否影响买家信任与经营 | 表现型（需查证） |

### 2.0 异常作用层级（决定基础分取列）

每个异常按作用层级分类，决定模块 4.1 基础分取哪一列：

- 变体级异常（命中具体子体，按命中变体的主要色/次要色/长尾色取列）：链接不可售、变体掉线、变体价差异常、主图异常、图片异常、A+ 异常、Buy Box 丢失、库存不可售、FBA 可售库存为 0、库存不足、合规异常，以及类目异常、属性信息异常中明确命中具体子体的情况。其中：链接不可售在子体层识别（每个子 ASIN 有各自前台展示与后台可售状态），按命中子体变体重要性取列并按 2.0.1 分层跳过；库存类异常（库存不可售、FBA 可售库存为 0、库存不足）在子体层识别、按命中子体变体重要性取列（其巡检频次由巡检频次规则文件统一维护，不在本知识库定义）。

- 链接级异常（整条链接的事，不分变体，取链接级异常基础分列）：以上之外的全部点位（父子体关系异常、标题异常、五点异常、促销异常、链接转化率异常下降、销量异常、ACOS 异常、广告花费异常、目标偏离、自然流量异常、卡位异常、放量未执行、库存积压、滞销异常、近期集中差评、评分异常、退款异常）。

合规与属性异常的层级规则：合规异常固定为子体级（变体级）异常，命中对象记录到具体子 ASIN，按命中子体的变体重要性取列；若平台合规限制作用于该父 ASIN 下全部子体，则按”全部子体命中”处理，视同波及主要色（基础分取主要色列，表现型巡检跳过规则按 2.0.1 执行）。类目异常、属性信息异常默认按实际命中对象判定：仅命中某个具体子体/变体字段的按变体级处理；影响父体整体、整条链接展示或平台审核的按链接级处理。

父子体关系异常的取列规则：该点位仅指父体被拆、全部子体从原父体结构中掉出，属于父体结构级 / 链接级异常；命中对象标注为父体 / 全部子体，基础分取链接级 S0=100，不再按主要色 / 次要色 / 长尾色拆分。

关于 ACOS / 广告花费 / 销量（父体级数据）：这三个指标取的是整个父体（所有变体的汇总集合）的数据——看的是整条链接的广告花费、ACOS、单量，不是某一个变体的。它们天然没有”哪个变体”的概念，因此归入链接级、不分变体重要性，基础分取二维表的链接级异常基础分列。

通用规则（兜底）：异常若被识别为发生在某个具体子体上，按该子体的变体重要性取列；发生在父体/Listing 整体的，按链接级异常基础分列取。上述清单为常见默认归类，实际命中对象与默认不一致时以通用规则为准；合规异常一律维持子体级，不适用链接级兜底。

异常类型（决定是否需要原因查证）：异常按是否需要原因查证分两类——表现型异常 = 模块 2.5 交易表现类 + 模块 2.7 售后异常类的全部点位（统计数字/比率/文字反馈，现象不等于原因，背后有多个可能原因，需经原因查证（模块 6.0）过滤出真实原因后再处理）；现象即原因型异常 = 以上之外的全部点位（现象本身即明确原因，或由平台直接给出，无需查证，直接按处理建议处理）。本规则按大类绑定：2.5、2.7 新增的点位自动归为表现型。

### 2.0.1 表现型异常巡检跳过规则

部分非表现型异常一旦命中，说明该链接（或该子体）已丧失正常展示或成交能力，此时表现型异常（销量、ACOS、广告花费、转化率、自然流量、卡位、售后等）的数据已失真甚至归零，继续巡检与查因无意义。命中下表标注”跳过”的点位时，本轮巡检跳过对该链接（或该子体，视命中层级而定）表现型异常的独立判定与查因；命中”不跳过”的点位时，表现型异常巡检正常进行，可正常触发模块 3.3 共因上调规则。判断标准：该异常发生时链接是否仍能正常展示、被浏览、被下单——不能则跳过，仍能则不跳过（与严重度高低无关）。

分层跳过原则（按命中对象）：下表跳过点位分三类。

① 无条件跳过——父子体关系异常：父体被拆、全部子体掉出，父体级表现型数据失真，一律跳过。

② 按命中变体重要性分层——链接不可售、Buy Box 丢失、主图异常、合规异常、变体掉线、库存不可售、FBA 可售库存为 0：命中主要色则跳过，命中次要色/长尾色则不跳过。级联规则：主要色命中②类点位时，因表现型异常为父体级汇总数据、已整体失真，跳过整个父 ASIN 的表现型巡检，其余次要色/长尾色不再单独触发；次要色/长尾色命中时，父体汇总仍由主要色撑住、数据仍有意义，不跳过父 ASIN，该变体问题按变体级异常单独处理，或作为查因中的并发原因（见模块 6.0）。若为整条 Listing / 全变体一起命中（无单一命中变体可分层），视同波及主要色，跳过。

③ 库存类异常（库存不可售、FBA 可售库存为 0）已并入②类，按命中子体的变体重要性分层跳过（主要色命中跳过、次要色/长尾色命中不跳过），与其它变体级状态类异常一致。

| 大类 | 异常点位 | 是否跳过表现型巡检 / 依据 |
| --- | --- | --- |
| 2.1 链接状态 | 链接不可售 | 主要色命中跳过 / 次要色·长尾色命中不跳过 —— 命中子体前台失效或后台不可售，无法正常展示/购买 |
| 2.1 链接状态 | Buy Box 丢失 | 主要色命中跳过 / 次要色·长尾色命中不跳过 —— 直接影响成交 |
| 2.1 链接状态 | 父子体关系异常 | 跳过 —— 父体被拆、全部子体掉出，父体级表现型数据失真 |
| 2.1 链接状态 | 变体掉线 | 视命中变体而定 —— 主要色掉线跳过（核心成交能力受损、表现型数据失真）；非主要色掉线不跳过（其余子体仍正常在售，链接整体仍可展示购买）。部分子体掉出统一归入本点位 |
| 2.2 内容完整性 | 主图异常 | 主要色命中跳过 / 次要色·长尾色命中不跳过 —— 主图缺失或错图，缺图时搜索中不可见/不可识别 |
| 2.2 内容完整性 | 图片异常 | 不跳过 —— 仍可购买展示 |
| 2.2 内容完整性 | 标题异常 | 不跳过 —— 仍可购买，只影响匹配/点击 |
| 2.2 内容完整性 | 五点异常 | 不跳过 —— 不影响展示购买能力 |
| 2.2 内容完整性 | A+ 异常 | 不跳过 —— 不影响展示购买能力 |
| 2.3 价格与促销 | 变体价差异常 | 不跳过 —— 不影响展示购买能力 |
| 2.3 价格与促销 | 促销异常 | 不跳过 —— 不影响展示购买能力 |
| 2.4 库存与可售 | 库存不可售 | 主要色命中跳过 / 次要色·长尾色命中不跳过 —— 主要色不可售时已丧失核心成交能力 |
| 2.4 库存与可售 | FBA 可售库存为 0 | 主要色命中跳过 / 次要色·长尾色命中不跳过 —— 主要色断货时已丧失核心成交能力 |
| 2.4 库存与可售 | 库存不足 | 不跳过 —— 尚可成交，仅有断货风险 |
| 2.4 库存与可售 | 库存积压 | 不跳过 —— 不影响成交能力 |
| 2.4 库存与可售 | 滞销异常 | 不跳过 —— 不影响成交能力 |
| 2.6 合规与属性 | 类目异常 | 不跳过 —— 仅影响识别/曝光，未实际受限 |
| 2.6 合规与属性 | 属性信息异常 | 不跳过 —— 同上 |
| 2.6 合规与属性 | 合规异常 | 主要色命中跳过 / 次要色·长尾色命中不跳过 —— 已命中平台合规限制；全部子体命中视同波及主要色，跳过 |
| 2.5 交易表现 / 2.7 售后 | 该两大类全部点位 | 不适用 —— 本身即”表现型异常”，是被判断的对象，不参与本规则 |

各点位严重度以模块 3.3 判定表为准，本表不重复定义严重度，仅定义是否跳过。

每轮巡检独立判断：命中跳过清单的非表现型异常，在该异常存续期间（未被运营标记解决 / 未自动恢复关闭），每轮巡检持续跳过对应表现型异常的独立判定与查因；该异常解除后，自下一轮巡检起恢复正常判断，包括是否触发新的非表现型异常、以及是否需要再次命中跳过清单。是否跳过为每轮巡检独立判定的动态结果，非一次触发后静态锁定。

跳过时的任务卡填写：命中跳过清单时，任务卡”判断依据 / 数据”栏只填该非表现型异常自身实际检测到的事实，不得填写”经营指标同步下滑”等未经检测的推测或具体经营数值（详见模块 7.0）。

### 2.1 链接状态异常

定义：产品链接在前台展示、购买路径、在售状态、父子体结构或平台状态上出现异常，导致链接无法正常展示、无法正常下单，或存在影响正常销售的状态风险，或链接的成交主导权（Buy Box）异常。

边界：判断链接本身是否还能正常展示、正常购买、正常销售。

| 问题点位 | 定义 |
| --- | --- |
| 链接不可售 | 链接前台无法作为正常在售商品展示，或后台状态不再属于正常可售范围。例如前台变狗、页面失效等；后台 ASIN 显示的字段为不可售、已禁止显示搜索结果或报价缺失。边界：链接前台失效 / 后台状态非可售导致的无法正常展示或购买，均归本点位；因库存维度导致的”有库存但不可售”归 2.4 库存不可售。作用层级：每个子 ASIN 都有各自的前台展示与后台可售状态，本点位在子体层识别、命中记录到具体子 ASIN，属变体级异常，按命中子体的变体重要性取列（模块 4.1），并按 2.0.1 分层跳过（主要色命中跳过、次要色/长尾色命中不跳过）。 |
| 变体掉线 | 原本挂在父体下的单个或部分子体脱离父体，导致买家无法在父体变体中选择该子体，但父体结构整体仍存在。边界：只要父体结构仍在、掉出的是部分子体（含原”父子体关系异常 · 部分子体掉出”场景），一律归本点位，不归父子体关系异常。 |
| 父子体关系异常 | 父体被拆，全部子体从原父体结构中掉出，父体和子体关系异常，影响变体展示或销售。边界：仅当父体结构被拆散、全部子体掉出时归本点位；部分子体掉出归”变体掉线”。两点位互斥，同一现象不得同时命中。 |
| Buy Box 丢失 | 商品未获得 Buy Box（链接仍在售，但未拿到黄金购物车，直接影响成交）。 |
