## 模块 4　运营输出规范

### 4.0 行为约束

1. **字段标准化：** 父卡级字段与异常明细基础字段固定输出，不因 P0/P1/P2 或异常类型不同而减少字段。
2. **原因字段：** 仅待查因型异常输出"初步原因/原因说明"；直接定因型异常不设置该字段。
3. **字段无数据：** 填"无/待补充/不适用"，不得省略字段。
4. **验证方式不外显：** 最终输出只输出已验证成立的原因、对应异常点位、判断依据和处理建议。
5. **跳过巡检时不编造数据：** 若本轮巡检命中触发豁免的非表现型异常，该链接的待查因异常未经检测，判断依据只填该非表现型异常自身事实，不得填写"经营指标同步下滑"等未经检测的描述。

### 4.1 示例输出

以下为一张父 ASIN 任务卡的示例。字段按结构化输出呈现。

> **示例产品：** T1 重点产品、收割期、旺季前期，同一父 ASIN 下两个异常。

**【任务卡】** 父 ASIN：B0XXXXXXX1 —— 男士速干运动 T 恤

**A. 定位信息**

| 字段 | 值 |
|------|-----|
| 店铺/站点 | hisuperus / Amazon_US |
| 父 ASIN | B0XXXXXXX1 |
| 产品定位 | T1 重点 |
| 产品阶段 | 收割期 |
| 淡旺季 | 旺季前期 |

**B. 优先级信息**

| 字段 | 值 |
|------|-----|
| 优先级 | **P0** |
| 处理时限 | **当天处理** |
| 异常分值 | 192.82 |
| 父卡严重度 | S0（取子体最高） |
| 当前状态 | 待处理 |

**C. 异常明细（按异常分值降序）**

**异常 1：FBA 可售库存为 0**
- 严重度：S0
- 异常分值：187.2
- 变体：主要色（黑色/M码）
- 判断依据：主要色 FBA 可售库存为 0，已断货
- 处理建议：已断货，请尽快安排补货。有广告投放→建议暂停或大幅降低广告预算

**异常 2：图片异常**
- 严重度：S1
- 异常分值：28.08
- 变体：长尾色
- 判断依据：副图数量不足
- 处理建议：请补充至少 3 张以上副图，提升转化承接

> **说明：** 异常分值由系统计算后结构化注入，Agent 不自行计算。主要色断货主导排序，长尾色图片异常记录在卡内但权重低。

### 4.2 待查因型异常查证后的示例输出

> **示例产品：** T1 重点产品、收割期、旺季前期。本轮巡检命中"链接不可售"且命中主要色（属豁免清单），因此跳过该链接的待查因异常检测。

**【任务卡】** 父 ASIN：B0YYYYYYY2 —— 女士防晒罩衫

**C. 主任务异常明细**

**异常：链接不可售**
- 严重度：S0
- 异常分值：(由系统计算)
- 变体：主要色
- 判断依据：主要色链接不可售，后台状态非可售
- 处理建议：链接无法正常购买，请检查后台可售状态

> **说明：** 链接不可售命中主要色、属豁免清单，本轮不对该链接的待查因异常（销量、ACOS、广告花费、自然流量、卡位等）进行检测，判断依据仅保留链接状态异常本身的事实，不产生关联现象。

### 4.3 共因去重 + 共因上调联动示例

> **示例产品：** T2 常规产品、维持期、淡季。命中"类目异常"（初判 S1），经查因确认为自然流量异常、卡位异常、销量异常 3 项的共同原因，触发共因上调，S1→S0。

**【任务卡】** 父 ASIN：B0ZZZZZZZ3 —— 儿童保温杯

**C. 主任务异常明细**

**异常：类目异常**
- 严重度：**S0（初判 S1，因确认为 3 项表现型异常共同原因，按规则上调至 S0）**
- 处理建议：商品类目错误或与产品不匹配，影响曝光和识别，请修正类目（沿用 S1 建议内容）
- 共因上调说明：经查因，类目异常同时导致自然流量异常、卡位异常、销量异常 3 项待查因异常

**D. 关联现象（不单独生成主任务）**
- 自然流量异常
- 卡位异常
- 销量下降

> **说明：** 运营最终看到"类目异常"主任务（已上调至 S0），以及 3 个关联现象。3 个待查因异常合并为关联现象，不重复生成主任务、不参与并发加成。
