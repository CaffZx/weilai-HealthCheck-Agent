## 模块 3　待查因型异常 

### 3.0 重要说明

> **🤖 LLM 操作说明——这是模块 3 的核心用法：**
>
> 1. **只有待查因型异常**（交易表现异常 + 售后异常）才进入本模块。**直接定因型异常跳过本模块**，直接到模块 3.2 取建议。
> 2. `root_cause` 由系统查因引擎**已经完成查证**，注入给 LLM 的是**最终结果**。
> 3. LLM 的职责：拿到 `code + root_cause` → 在本模块各小节找到匹配的 `root_cause` → 输出对应的**原因说明 + 处理建议**。
> 4. 如果 `root_cause = null`（系统未定位到原因）→ 输出该小节的**兜底话术**。
>
> **系统注入的格式示例：**
> ```
> 异常: {code: "ACOS异常", severity: "S0", root_cause: "CPC上升"}
> 异常: {code: "退款异常", severity: "S1", root_cause: null}     ← 未查到原因，输出兜底
> 异常: {code: "库存不足", severity: "S0", root_cause: null}     ← 直接定因型，跳过模块 3
> ```
>
> 每条异常 LLM 需要输出两部分：
> 1. **原因说明**：用大白话解释为什么出现这个异常（含 root_cause 信息）
> 2. **处理建议**：指向该异常对应的 1~2 条具体动作

### 3.0.1 链接转化率异常下降

> 系统注入 `root_cause` 取值及 LLM 输出对照：

| root_cause | LLM 输出的原因说明 + 处理建议 |
|-----------|---------------------------|
| `优惠/Coupon失效` | 原因：优惠或 Coupon 未生效，导致转化率下降。建议：检查 Coupon 和促销活动配置，重新提交 |
| `图片异常` | 原因：副图展示异常，影响买家对产品的完整认知。建议：指向「图片异常」待办处理 |
| `标题/五点/A+异常` | 原因：页面内容存在异常，影响承接转化。建议：指向「内容完整性异常」待办处理 |
| `内容改动` | 原因：近期 listing 内容可能有改动，影响转化承接。建议：核查近期是否修改过主图/A+/标题等 |
| `差评增多/评分下降` | 原因：差评或评分下降导致买家信任降低，转化率下滑。建议：指向「售后异常」待办处理 |
| `非主要色链接状态异常` | 原因：非主要色链接状态异常，影响链接展示。建议：指向「链接状态」待办处理 |
| `部分变体掉线 / 部分子体库存异常` | 原因：部分变体掉线或子体库存异常，影响链接成交能力。建议：指向「库存/变体异常」待办处理 |
| `价格竞争优势下降` | 原因：本品价格相对竞品变贵，转化率受影响。建议：监测到价格竞争优势下降（本品 ${X}→${Y}，竞品 ${Z}→${W}），请评估是否调整价格 |
| `竞品变体结构更丰富` | 原因：竞品变体数量多于本品，分流了转化。建议：竞品 {N} 个变体、本品 {M} 个，缺 {具体变体}；请评估是否补齐 |
| `市场新增竞品` | 原因：类目出现新竞品，分流了流量和转化。建议：监测到 {N} 个新竞品进入 {关键词/类目}，请评估竞争策略 |
| `null`（未定位到原因） | **兜底：** 经查内部无异常、竞品无明显变化，转化率下降原因待人工进一步核查。若转化率 < 类目均值 50%，建议考虑更换 listing；若在 50%~99%，建议 A/B 测试优化 |

| `库存能否支撑` | 销量上升但库存不足，预计 {X} 天断货：① 尽快补货；② 若来不及，同步试探性涨价放缓消耗 |

### 3.0.3 ACOS 异常

> 系统注入漏斗数据（第一层）和 root_cause（第二层）。  
> **第一层**：列出四环数据定位恶化环节。  
> **第二层**：若 CTR 或 CVR 恶化，根据 root_cause 匹配下方输出。
输出必须包含"当前acos,近三天平均acos,目标acos,acos异常，请转入广告agent界面判断是否需要调整目标acos"
**第一层：拆广告漏斗（ACOS = CPC ÷（CVR × 客单价））**

| 环节 | 输出内容 |
|------|---------|
| 点击成本环 | 列数据：CPC ${X}→${Y}，广告位花费{分布}，总花费{Z}；点击成本上升，提示广告侧关注（不触发第二层） |
| 点击率环 | 列数据 + 触发第二层深查 |
| 转化环 | 列数据 + 触发第二层深查 |
| 客单价环 | 列数据：客单价 ${X}→${Y}；查是否并发价格与促销异常→命中则指向「价格与促销异常」对应待办；否则提示核查是否为运营主动降价/主动促销。若为主动降价/促销，不作为价格异常修复，建议运营同步下调广告 CPC 以匹配新客单价 |

**第二层：CTR 或 CVR 任一下降时，查承接端原因（root_cause → 话术）**

| root_cause | LLM 输出的原因说明 + 处理建议 |
|-----------|---------------------------|
| `评分/差评/高退换货风险变差` | 原因：评分/差评或高退换货风险影响转化，导致 ACOS 升高。建议：指向「售后异常」待办处理 |
| `A+等内容异常` | 原因：A+ 或页面内容存在异常，影响转化效率。建议：指向「内容完整性异常」待办处理 |
| `内容改动` | 原因：近期 listing 内容可能有改动，影响转化承接。建议：核查近期是否修改过主图/A+/标题等 |
| `价格竞争优势下降` | 原因：本品相对竞品变贵，转化率下降导致 ACOS 升高。建议：本品 ${X}→${Y}，竞品 ${Z}→${W}，请评估是否调整价格 |
| `非主要色链接状态异常` | 原因：非主要色链接状态异常，影响转化。建议：指向「链接状态」待办处理 |
| `部分变体掉线 / 部分子体库存异常` | 原因：部分变体掉线或子体库存异常，影响链接成交。建议：指向「库存/变体异常」待办处理 |
| `广告投放问题`（兜底） | **兜底：** 经查承接端无明确异常，疑似广告投放本身问题；列出广告漏斗数据，转广告 Agent/运营处理 |

### 3.0.4 广告花费异常

> 广告花费异常 = 实际广告花费连续 ≥3 天偏离近 7 天平均花费（双向：花费超出 / 花费不足）。所有指标对比口径统一：近 3 天 vs 近 7 天均值。
输出必须包含"当前广告花费,近三天平均广告花费,目标预算,广告花费异常，请转入广告agent界面判断是否需要调整目标预算"
**方向一：花费超出（实际广告花费高于正常）**

不纠结具体成因，直接看近 3 天 ACOS（对比目标 ACOS）判断是健康增长还是浪费。

**基础输出（必出）：** 花费（近 3 天）从 ${X} 增加到 ${Y}（较近 7 天均值 +{Z}%），请运营排查是否正常情况（是否主动加投/流量变化等）

| ACOS 情况 | 成立后输出 |
|-----------|---------|
| ACOS 健康 | 广告花费异常 · 花费超出已触发，但近 3 天 ACOS 健康（近 3 天 {X}<目标 {Y}），暂判断为高效增长型花费上升；建议运营确认是否为主动加投，并关注自然流量承接和预算分配，判断是否需要将预算向高效流量倾斜 |
| ACOS 不好 | 花费增长且 ACOS 偏高（近 3 天 {X}≥目标 {Y}），存在花费浪费；若同时正式命中 ACOS 异常，则按 ACOS 异常对应查证结果和处理建议输出，广告花费异常 · 花费超出作为异常明细和关联现象保留 |

**方向二：广告花费异常 · 花费不足（实际广告花费低于正常）**

花费不足多为机会损失，但也可能是效率提升或自然替代（好事）。用漏斗诊断：看花费下降时，曝光/点击/订单/广告单/自然单（均近 3 天 vs 近 7 天均值）怎么变，据此定位。

**基础输出（必出）：** 花费（近 3 天）较近 7 天均值 -{Z}%，从 ${X} 降到 ${Y}，触发广告花费异常 · 花费不足

**必出提示：** 提示运营核查：本次花费下降是否为近期主动调低预算/出价所致；若是，属主动调整，确认即可

| 数据表现（近3天 vs 近7天） | 原因方向 | 成立后输出 |
|------------------------|---------|-----------|
| 花费↓ 曝光↓ 点击↓ | 广告拿不到展示 | 出价偏低/竞争致曝光不足，建议评估提高出价；另提示运营核查关键词覆盖是否不足/匹配过窄（系统无法查，可扩词/放宽匹配） |
| 花费↓ 曝光持平 CTR↓ | 买家不愿意点 | CTR 下降、买家不愿点；查主图 / 价格 / 评分 / 售后风险 → 命中则指向「内容完整性异常 / 价格与促销异常 / 售后异常」对应待办 |
| 花费↓ 点击持平 订单持平 | 健康型花费下降 | 花更少钱拿到同样点击与订单，属于健康型花费下降，无需按负向异常处理；提醒关注后续花费是否持续走低影响放量空间，可考虑将节省预算用于扩量 |
| 花费↓ 广告单↓ 总单持平（自然单上升补足） | 自然替代广告（健康型花费下降） | 广告单下降但自然单上升补足、总单稳定，属于自然替代广告的健康型花费下降；建议运营确认是否可顺势降低广告依赖，或将预算转向更高效流量 |
| 花费↓ 广告单↓ 总单↓ | 已影响目标单量 | 广告花费异常 · 花费不足以拖累总单量、影响目标达成，需重视；关联「目标偏离」 |
| 花费↓ 广告单↓ 自然单也↓ | 上游承接 / 市场 / 产品力问题 | ① 命中链接状态异常：输出对应链接状态点位及模块 6.2 处理建议，广告花费异常 · 花费不足作为关联现象展示。② 命中库存与可售异常：输出对应库存异常点位及模块 6.2 处理建议，广告花费异常 · 花费不足作为关联现象展示。③ 命中竞品广告活跃度下降或市场需求下降：输出市场流量整体变弱提示，建议观察或评估市场变化。④ 本行分支均未命中：进入最终兜底 |

**兜底（以上数据表现均不匹配时）：** 花费下降但漏斗各环无明显匹配/在正常波动内，原因不明确；提示运营核查广告投放设置与近期调整

**输出规则：** 广告花费异常需作为任务卡异常明细展示，并按花费超出 / 花费不足方向展开。若查证命中已有异常点位（如链接状态、库存、内容完整性、价格与促销、售后等），则引用该点位在模块 6.2 中的对应处理建议，广告花费异常作为异常明细和关联现象展示；不直接输出"提高出价/扩词"等广告侧动作。若未命中已有异常点位，再按广告漏斗或市场侧原因输出对应建议。能查的给数据、查不到的提示运营核查；广告内部问题转广告 Agent/运营处理。

### 3.0.5 目标偏离

| root_cause | LLM 输出的原因说明 + 处理建议 |
|-----------|---------------------------|
| `广告依赖型` | 第零层定位：自然订单占比 < 30%，属广告依赖型。建议：广告侧问题优先，转 ACOS 异常/广告花费异常查因 |
| `混合型` | 第零层定位：自然订单占比 30%~55%，属混合型。建议：自然侧和广告侧都要检查，建议优先处理已命中的异常 |
| `自然驱动型` | 第零层定位：自然订单占比 > 55%，属自然驱动型。建议：自然侧问题优先，检查流量入口、点击率、转化率 |
| `流量不够` | 原因：流量入口不足。建议：检查广告投放的关键词覆盖、自然流量入口 |
| `点击不够` | 原因：点击吸引力差。建议：检查主图、标题、价格竞争力 |
| `转化不够` | 原因：链接承接差。建议：检查 A+、五点、评价、变体结构 |
| `竞争力不够` | 原因：各环都行但整体打不过竞品。建议：检查竞品对比——价格/变体/评分/广告投入 |
| `目标可能不合理`（兜底） | **兜底：** 经排查无异常、无明确可优化动作，仍不达标。建议重新评估目标单量是否合理 |

### 3.0.6 售后异常（差评/评分/退款）

> **⚠️ 本小节特殊——LLM 需要自主阅读评论内容。**
>
> 系统注入 `root_cause` 可能为 null，同时将**评论原文/退款理由原文**注入。  
> LLM 需自主阅读文本，归类出造成售后异常的主要原因（按占比排序），再匹配下方输出。

| LLM 归类结果 | 输出的原因说明 + 处理建议 |
|-------------|------------------------|
| `产品质量问题` | 原因：买家反馈产品质量问题（占比 {X}%）。建议：反馈供应链改进质量，检查该批次产品 |
| `尺码问题` | 原因：买家反馈尺码不符（占比 {X}%）。建议：更新尺码表，增加尺码指引说明 |
| `描述不符` | 原因：买家反馈产品与页面描述不一致（占比 {X}%）。建议：修正 Listing 描述和图片，确保与实际一致 |
| `物流问题` | 原因：买家反馈物流配送问题（占比 {X}%）。建议：反馈仓储/物流侧改进包装或配送时效 |
| `原因分散/置信度低` | **兜底：** 退款/差评/评分原因分散，无明显主因，建议人工复核评论或退款理由 |

### 3.0.7 自然流量异常

**第一层：看"自然 vs 广告关系"归类原因方向**

| 数据表现 | 原因方向 | 成立后输出 |
|---------|---------|-----------|
| 自然单↓ 总单↓ | 真自然流量下滑 | → 进第二层查具体病因 |
| 自然单↓ 总单稳定 | 广告补住总单，自然腿变弱 | 总单被广告掩盖、自然在恶化（易被忽视）；→ 进第二层查病因 |
| 自然单稳定或上升，但自然单增幅低于总单增幅 | 增长依赖广告，自然没跟上 | 总单上涨但自然未同步增长，增长靠广告推动、自然权重没跟上，增长质量不健康；建议关注自然流量提升（核心词排名），让自然跟上增长 |
| 广告单↑ 总单不涨 | 广告替代自然单 | 广告单增但总单未涨，广告在替代本可免费获得的自然单。建议：① 削减无效替代的广告花费；② 将预算转投到能带动自然流量增长的广告活动上（核心词排名、精准广告），主力恢复自然位 |

**第二层A：自然单↓、转化率未降 → 自然流量入口减少（内部）**

| 可能原因 | 成立后输出 |
|---------|-----------|
| 卡位下滑 | 指向「卡位异常」待办 |

**第二层B：自然单↓、转化率也↓ → 链接承接/转化变差（内部）**

| 可能原因 | 成立后输出 |
|---------|-----------|
| 转化率下降 | 指向「链接转化率异常下降」待办 |
| 价格竞争优势下降（变化型） | 监测到价格竞争优势下降：本品 ${X}→${Y}、竞品 ${Z}→${W}；请评估 |
| 非主要色链接状态异常 | 指向「链接状态」待办 |
| 库存异常（可售变体减少） | 指向已命中的库存与可售异常具体点位处理建议（可售变体少，承接不了自然流量） |
| 新增差评（信任下降） | 指向「售后异常」待办 |

**第二层C：外部（竞品/市场）**

| 可能原因 | 成立后输出 |
|---------|-----------|
| 市场需求整体下降 | 监测到直接竞品大类排名普遍下滑，疑似市场需求整体下降；非本品独有，请评估 |

**兜底：** 提示运营核查核心词自然排名是否下滑、自然流量来源是否异常

### 3.0.8 卡位异常

> 卡位下滑 = 被竞品超过，原因分两类：自己变弱，或竞品变强。不预先判断，由查证结果自然得出。

**第一组：查自己是否变弱（指向已有异常待办）**

| 可能原因 | 成立后输出 |
|---------|-----------|
| 销量下滑 | 指向「销量异常」待办 |
| 转化率下降 | 指向「链接转化率异常下降」待办 |
| 自然流量减少 | 指向「自然流量异常」待办 |
| 评分/差评（信任下降） | 指向「售后异常」待办 |
| 价格竞争优势下降（变化型） | 监测到价格竞争优势下降：本品 ${X}→${Y}、竞品 ${Z}→${W}；请评估 |
| 部分变体掉线 / 部分子体库存异常 | 指向已命中的库存与可售异常或变体相关异常具体点位处理建议 |

**第二组：查竞品是否变强（提示评估）**

| 可能原因 | 成立后输出 |
|---------|-----------|
| 竞品卖得越来越好 | 监测到竞品[{ASIN}]大类排名上升、卖得更好，把本品挤下；请评估竞争策略 |
| 竞品降价 | 监测到竞品[{ASIN}]降价（${X}→${Y}）；请评估应对（跟价/coupon） |
| 竞品上新/变体丰富 | 监测到竞品[{ASIN}]上新/变体增多，分流了流量；请评估补齐变体/差异化 |

**兜底：** 本品指标无下滑、已知竞品无明显动作，但卡位仍下滑，可能是直接竞品集合发生变化（ERP 纳入了新的更强竞品，参照系改变）；提示运营核查竞品集合

核心逻辑：目标单量没完成 → 先拆"广告单 vs 自然单"定位问题在哪侧 → 自然侧/整体走漏斗（曝光/点击/转化）拆原因 → 结合价格/库存/评价/竞品判断 → 都正常则排查主动动作是否缺失。

**第零层：先拆广告单 vs 自然单**

| 定位结果 | 输出 |
|---------|------|
| 自然订单占比 < 30% | 广告依赖型——广告侧问题优先，转 ACOS 异常/广告花费异常查因 |
| 自然订单占比 30%–55% | 混合型——自然侧和广告侧都要检查 |
| 自然订单占比 > 55% | 自然驱动型——自然侧问题优先，走第一层漏斗 |

**第一层：拆漏斗定位缺口环节（结果由系统注入）**

**第二层：针对定位的环节查具体原因**

| 环节 | 原因 | 输出 |
|------|------|------|
| 流量不够 | 流量入口不足 | 检查广告投放的关键词覆盖、自然流量入口 |
| 点击不够 | 点击吸引力差 | 检查主图、标题、价格竞争力 |
| 转化不够 | 链接承接差 | 检查 A+、五点、评价、变体结构 |
| 竞争力不够 | 整体打不过 | 检查竞品对比——价格/变体/评分/广告投入 |

**第三层：最终兜底（前面各层都无明确指向时）**

质疑目标本身：经排查无异常、无明确可优化动作，仍不达标→建议重新评估目标合理性。

**输出规则：** 嵌入父卡明细。显示三窗口数据（当日/近3天/近7天实际 vs 目标、月累计完成率）。

## 3.2 处理建议表

> **待查因型异常**（交易表现异常、售后异常）已在 3.0 中设置独立查因与输出逻辑，不在本节重复设置。
