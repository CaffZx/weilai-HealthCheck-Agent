# 知识库（当前切片版）

当前知识库按 5 个业务模块切片。运行时由 `core/knowledge_loader.py` 读取这些模块；修改文件后，下一次判定会加载最新内容。

| # | 切片 | 主要内容 |
|---|---|---|
| 00 | [切片索引](00_切片索引.md) | 切片职责、依赖和检索入口 |
| 01 | [模块 0：关键术语](01_模块0_关键术语.md) | S / T / P 术语与边界 |
| 02 | [模块 1：异常字典](02_模块1_异常字典.md) | 异常定义、分类和适用边界 |
| 03 | [模块 2：严重度通用原则](03_模块2_严重度通用原则.md) | 作用层级、S0/S1/S2、共因上调 |
| 04 | [模块 3：查因与处理建议](04_模块3_查因与处理建议.md) | 待查因逻辑、原因说明和处理建议 |
| 05 | [模块 4：运营输出规范](05_模块4_运营输出规范.md) | 任务卡输出字段和运营展示规范 |

## 关键约定

- **S = 异常严重度**（S0/S1/S2）— 判定输入
- **T = 产品定位**（T0/T1/T2/T3）— 权重
- **P = 执行优先级**（P0/P1/P2）— 最终输出
